# Analytics Work Samples

Selected analytics work prepared for the Macquarie University Data Analyst
Intern interview process.

## Projects

### Victoria Road Crash Analysis

An individual analysis of Victorian road-crash data using Python and R. The
project covers data cleaning, integration, imputation, geographic analysis,
time-series analysis, and injury-severity comparisons.

### Salesforce Australia SMB Opportunity Dashboard

A university group project that sized and located potential SMB CRM
opportunities across Australia. My contribution focused on the data
architecture and dashboard engineering, including the interactive dashboard
and the Tableau package covering grants and business formation.

## Notes

- Each project folder contains its own documentation and supporting files.
- Large raw source datasets are not included. The source data is described in
  the project documentation and the road-crash data dictionary.
- The road-crash report is a public submission copy with course, instructor,
  and student-identification details removed.
- The Salesforce project is a team deliverable. The project README identifies
  my contribution and does not present the complete analysis as individual
  work.
